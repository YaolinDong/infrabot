# Reporting a security issue

Report security issues privately to the maintainer at dong1505lin@gmail.com, not in a public issue. Name the affected repository and version, describe the impact and include a minimal way to reproduce it. Remove credentials, device addresses and private signing material from logs.

请不要在公开 issue 中报告安全问题，请发邮件到 dong1505lin@gmail.com 私下联系维护者。写明受影响的仓库和版本、影响范围和最简复现方法；日志中请去掉密码、设备地址和私有签名材料。
