# 演示视频

每段视频展示控制器上的一种本地模式。这些模式在 STM32H743 上以 1 kHz 运行，不需要 PC 持续发指令；视频里都是用手推动和拖动机械臂。视频已去掉声音。模式演示每段约 13–23 秒，触摸屏操作视频 37 秒。各模式的原理见[控制模式](firmware/control-modes.md)。

<Clip name="joint-impedance">**关节阻抗。** 每个关节上的弹簧阻尼把机械臂拉回进入模式时锁定的平衡位置。</Clip>

<Clip name="cartesian-impedance">**笛卡尔阻抗。** 末端的弹簧阻尼把末端拉回锁定的位姿。</Clip>

<Clip name="joint-admittance">**关节导纳。** 估计的外力矩驱动每个关节的虚拟质量，关节会顺着推力运动。</Clip>

<Clip name="cartesian-admittance">**笛卡尔导纳。** 末端在笛卡尔空间里作为虚拟质量，顺着推力运动。</Clip>

## 屏幕 3D 视图

触摸屏上的 3D 视图由控制器根据实测关节角绘制，同时显示末端位置。用手移动机械臂时，画面跟着同步运动。

<div className="demos">

<Clip name="gravity-compensation-screen">**重力补偿。** 用手拖动机械臂，屏幕视图跟着运动。</Clip>

<Clip name="joint-impedance-screen">**关节阻抗。** 推开机械臂后它弹回原位，屏幕上同步显示。</Clip>

</div>
