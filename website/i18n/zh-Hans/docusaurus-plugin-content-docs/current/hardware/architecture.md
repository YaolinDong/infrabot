# 系统结构

```text
PC：C++ / Python SDK、Qt 界面
 ▲
 │  以太网 UDP：指令向下，遥测和回复向上
 ▼
控制器：底板上的 STM32H743，带触摸屏
        1 kHz 关节控制环 · 运动学 · 重力补偿 · 阻抗 · 导纳
 ▲
 │  CAN FD：驱动指令向下，电机反馈向上
 ▼
关节电机：J1–J2 DM8009P · J3–J4 DM4340P · J5–J7 DM4310 · J8 夹爪
```

- **驱动器只由控制器直接控制。** 只有 STM32H743 和电机通信，PC 通过 UDP 发送目标或模式请求。
- **同一时间只有一台 PC 拥有控制权。** 有效的运动或配置请求会把控制权绑定到发送方地址；机械臂使能或运动期间，其他来源的请求会被拒绝。STOP 和 DISABLE 始终会被接受。
- **触摸屏在本地操作。** 不接 PC 也能使能驱动器、切换模式、调节柔顺参数和停止机械臂。
- **两个使能组。** J1–J7 是机械臂组；夹爪 J8 单独使能，也可以不接。

## UDP 端口

| 端口 | 用途 |
|---|---|
| 5000 | 遥测注册、遥测、回复和时钟同步 |
| 5001 | 信息查询、指令和运动会话 |
| 5002 | 固件升级 |
| 5003 | 板上日志下载 |
