# 安全

InfraBot 是研究用机械臂，不是经过认证的工业机器人或协作机器人。使用前请针对自己的使用场景评估风险。

:::danger 硬件急停
触摸屏 STOP、面板按键、SDK 的 `stop()` 以及控制器的软件超时**都不会切断驱动器电源**，也不能让已经故障的驱动器停下来。请接一个能断开电机动力电的独立急停。
:::

## 第一次上电前

- 把底座用螺栓固定在足够刚硬的台面上，能承受机械臂运动时的反作用力矩。
- 使能前在触摸屏上核对关节零位、关节方向和电机模式。固件上电时所有驱动器都是失能的，也不会自动设置零位。
- 清空机械臂（包括夹爪和工具）能够到的范围；机械臂使能时，人员不要进入这个范围。

## 停止

| 操作 | 结果 |
|---|---|
| 触摸屏 STOP、底板 KEY1 或 SDK `stop()` | 制动，并**保持使能、进入 IDLE 保持** |
| PC 必须持续发送的指令流中断 | 同样的受控停止 |
| 失能驱动器 | 撤掉驱动器力矩，所以先把机械臂支撑好 |
| 硬件急停 | 切断驱动器电源，只有它能做到 |

重力补偿、阻抗和导纳在控制器上运行，**PC 断开后仍会继续**。结束这类操作前先按 STOP。

## 限制

关节位置、速度和力矩限制是控制器里的软件监控，驱动器本身还有自己的 PD 输出。这些限制只能作为最后一道防线，不能当作安全功能。电机反馈的力矩包含重力、加速和摩擦，不是接触力测量值。

## 维护和升级

升级固件或改接线之前，先支撑好机械臂、失能驱动器、断开电机动力电，控制器保持供电以便通信。只安装由板上 Loader 信任的发布者签名的固件。
