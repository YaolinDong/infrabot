# 固件升级

Flash 里有一个常驻 Loader 和 A、B 两个应用槽。发布包（`.ifw`）包含两个槽各自的签名镜像。

1. SDK 的升级工具先在 PC 上校验发布包签名。
2. 通过以太网升级时，控制器在触摸屏上显示来源地址和镜像 ID，必须在 60 秒内点**允许**。拒绝或超时都会在擦写之前取消升级。
3. 控制器写入未使用的槽，并试启动新固件。
4. SDK 确认新固件已经运行。未确认或试启动失败时，会回到原来的固件。

用 CMSIS-DAP 调试器走 SWD 是独立的升级方式，使用同一个签名包，不需要网线和触摸屏。新板或空板需要先用 SWD 烧一次出厂镜像。

升级前先支撑好机械臂、失能驱动器、断开电机动力电，控制器保持供电。

## 发布者密钥

板子只接受板上 Loader 信任的发布者签名的固件。公钥随固件和 SDK 一起提供。如果要发布自己编译的固件，请生成自己的 Ed25519 密钥，私钥不要放进任何仓库，并给板子烧写用这把公钥编译的 Loader。更换板子信任的发布者需要通过 SWD 操作。
