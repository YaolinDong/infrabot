# 控制模式

固件把**电机配置**和**执行模式**分成两层：先在所有驱动器失能时选择电机模式，再使能机械臂，然后从 IDLE 进入执行模式。

```text
电机配置（所有驱动器失能时）
├─ J1–J7 MIT
└─ J1–J7 位置速度                J8 夹爪：始终为力位混合

执行模式（使能后从 IDLE 进入）
├─ IDLE                 保持当前位置，不接受运动目标
├─ RT 关节 / 笛卡尔      PC 发送目标流，通常 1 kHz
├─ NRT 关节 / 笛卡尔     控制器插值执行 movej / movep 目标
├─ 重力补偿 FREE / LOCK  本地重力补偿
├─ 关节 / 笛卡尔阻抗     本地弹簧阻尼
└─ 关节 / 笛卡尔导纳     本地虚拟质量
```

| 模式 | 控制环在哪里运行 | 运行期间 PC 需要发送什么 |
|---|---|---|
| IDLE | 控制器保持已使能的驱动器 | 心跳，默认 100 Hz |
| RT 关节 | PC 给目标，控制器以 1 kHz 驱动电机 | 关节目标，通常 1 kHz |
| RT 笛卡尔 | PC 给末端位姿，控制器求逆运动学 | 末端位姿，通常 1 kHz |
| NRT 关节、NRT 笛卡尔 | 控制器规划并执行 `movej` / `movep` | 一个目标，之后以 100 Hz 维持会话 |
| 重力补偿 FREE、LOCK | 控制器，1 kHz | 进入模式后不需要 |
| 关节、笛卡尔阻抗 | 控制器，1 kHz | 进入模式后不需要 |
| 关节、笛卡尔导纳 | 控制器，1 kHz | 进入模式后不需要 |

## 规则

- RT 和 NRT 之间必须经过 IDLE 切换；更换电机模式必须先失能所有驱动器。
- 使能只会进入 IDLE 保持。固件不会自己回零、开始目标流或提交运动。
- 机械臂未使能、零位未设置、反馈过期、电机模式不对或驱动器温度过高时，固件拒绝进入本地模式。
- 必须持续发送的指令流中断 100 ms 后，控制器制动并保持使能。停止原因允许时，RESUME 会从保持的位置回到原来的模式。

## 本地柔顺控制

- **重力补偿**使用 H7C 裸臂模型，质量、质心和关节偏置都经过辨识。FREE 可以手动拖动，关节阻尼保持生效；LOCK 以可调的刚度保持当前位姿。
- **阻抗**在重力前馈之上，在关节空间或末端施加弹簧阻尼，保持固定的平衡位置。它使用驱动器的 MIT 力矩接口，不测量接触力。
- **导纳**根据估计的外力矩驱动一个虚拟质量运动，可以在关节空间或末端进行。

进入和退出每个本地模式时，增益和力矩都会平滑过渡，不会突然卸掉负载。STOP 会在 0.5 s 内恢复到保持增益。
