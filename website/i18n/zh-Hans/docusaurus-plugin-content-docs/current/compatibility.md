# 版本兼容

每个仓库各自发布版本，“发布组合”列出一起测试过的版本。

| 发布组合 | 机械臂 | 固件 | SDK | 协议 | 描述包 | 控制器 |
|---|---|---|---|---|---|---|
| 2026.1 | H7C | 0.1.0 | 0.1.0 | 1.0 | 0.1.0 | 野火 H743 挑战者 V2 核心板；4.3 寸底板 R8 |

## 协议

权威的 `protocol.h` 在固件仓库，SDK 里有一份逐字节相同的副本，SDK 的测试会比对两者。

- SDK 连接时先向控制器查询协议版本，然后才启动心跳、发送指令。
- **主版本**必须一致；不一致时 `connect` 失败，并报告两边的版本。
- **次版本**只增加功能。可选功能按控制器报告的能力位判断。
- 只支持旧 V1 信息请求的固件按协议 1.0 处理，固件版本显示为未知。

## 机器人模型

固件的重力模型和机器人描述包使用同一套 H7C 裸臂参数：质量、质心、惯量、关节原点和限位。夹爪和工具不在模型里。
