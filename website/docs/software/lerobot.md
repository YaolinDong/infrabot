# LeRobot

A [LeRobot](https://github.com/huggingface/lerobot) robot plugin (`lerobot-robot-infrabot`) is planned for teleoperation, dataset recording and policy deployment. LeRobot discovers third-party robot packages whose names start with `lerobot_robot_`, so the plugin will install as `lerobot_robot_infrabot`. It will build on the Python SDK.
